# txa

Command line tools for the TXA Windows package repository.

```
pipx install txa
```

| Command | Purpose |
|---|---|
| `txapm` | install, upgrade, uninstall, list, search, export/import TXA packages |
| `txacreate` | sign in to GitHub and publish installers as pull requests (`new`, `update`, `hash`) |
| `txaci` | the 16-step manifest validator used by the repository bot |

Source, manifest format and docs: https://github.com/TXAVL/txa-repo
